# 运行时子项合成与替换

**Languages:** [English](runtime-handoffs.md) | [한국어](runtime-handoffs.ko.md) | [日本語](runtime-handoffs.ja.md) | [简体中文](runtime-handoffs.zh-CN.md)

本参考适用于确实提供这些服务的宿主。技能不会把 ng.compile、ng.replace 或想象中的 MCP 替换工具变成 API。兼容性 Harness MCP 接口能够编译/启动工作流；实时替换需要此处描述的原生宿主集成。

## 必需的宿主信息包

从提供的宿主服务获取有效的所有者/运行/版本、当前谱系头、可用注册表、提案模式（模板参数或完整源码）、输入/输出契约、剩余限制，以及结果/诊断格式。如果请求中尚未包含这些信息，检查可用配置。指出缺失的契约，不要猜测绑定或声称某个操作已经执行。

模型提出源码或参数。宿主提供权限并执行原子状态变更。提供方凭据和可信授权保留在宿主端。

## 创建子项

1. 针对具体的子任务和所需输出，提出源码或模板参数。只请求父项允许的能力和剩余额度。
2. 在要求的边界提交宿主的提案封装。宿主绑定实际父项/谱系头、预留资源、编译、验证语义、准入、发布并绑定子项。模型提供的授权不具有权限效力。
3. 读取结果。被拒绝时，使用返回的诊断和剩余修复额度。绑定成功时，使用准确的子项绑定和输入契约。
4. yield 已准入的 spawn 命令；需要结果时，将其包在 await 中。记录子项结果或准确的失败原因；不要把排队中的提案报告为已经执行的子项。

例如，聊天机器人经过审查的 review 模板会输出带有 kind="review"、turn 和 source 的检查点。宿主派生名称 "review-" + turn，并在绑定之前对照经过审查的模板验证源码。这些字段名只属于该示例，并非通用提案模式。

## 替换当前 Harness

1. 构建显式可序列化状态，包含继任者需要的内容：对话/任务进度，以及重新加入保留工作所需的准确输入。
2. yield checkpoint(state, stableSite)。宿主在该边界保留租约。
3. 宿主持久记录合成意图，预留一次动态编译，编译/验证/准入继任者，并通过生成代次 CAS 选定该确切版本进行替换。
4. 继任者启动新的生成器。在执行新工作前，从 input.handoff 恢复声明的交接状态；存在交接时，不要从头初始化计数器/历史记录。宿主还会绑定 previous_run_id。
5. 保持逻辑父项、子项关系、输出契约和授予权限的兼容性。剩余的不可续充资源转移给继任者。

跨越边界的是 JSON 状态，而不是 QuickJS 堆、生成器栈、指针、Promise 或原生句柄。已发布的图/版本不可变。

## 保留的子项与恢复

保留子项的绑定和原始输入标识已有工作。在当前原生运行时中，使用继承的绑定及其已记录输入执行 spawn，会重新加入该子项。输入按规范化 JSON 内容比较，而不是按原始文本中的键顺序比较；更改该内容会造成冲突。新任务需要新的宿主准入绑定，以及新预留且权限递减的子项预算。替换不得重复已完成的外部工作，也不得恢复已花费的额度。

遇到过期谱系头冲突时，重新加载活动生成代次。提供方或编译器结果不确定时，必须通过提供的宿主路径对账；不要仅因为没有可用回答就重新派发。遵循宿主返回的逻辑家族取消契约，不要假定取消会从子项传播到父项或作用于全局。如实报告返回的执行保证。

## 原生宿主实现入口

- RuntimeConfig::checkpoint_handler：将句柄/租约入队，然后及时返回。保留租约会暂停该生成代次；宿主工作应在调度器之外执行。
- ProgramRuntime::prepare_child_synthesis：将提案和宿主单独签发的权限授权绑定到已持有的父项检查点。该授权不会补充父项剩余的编译预算或墙钟时间预算。
- ProgramSynthesisGateway：编译、语义验证和 Catalog 准入。
- ProgramRuntime::reserve_synthesis：通过预期谱系头 CAS 扣除一次尚未分配的编译额度；保留检查点身份的同时，刷新租约的日志头。
- ProgramRuntime::replace：消费已持有的检查点和已准入的目标，使用显式交接/前驱输入以及源端剩余额度。
- reconnect/recover_child_synthesis：恢复已记录的生成代次/阶段，或返回对账要求。

这些名称是 C++ 宿主 API，而不是 JavaScript 命令或自动提供给模型的工具。使用实际仓库头文件/服务模式查阅签名及完整调用方式。生成器控制保留该 API 的 Unmanaged 执行保证；这个标签不意味着宿主控制不存在。编译器接受不代表行为质量已获证明。
