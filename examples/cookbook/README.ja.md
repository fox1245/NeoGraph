| [`the-beast/`](the-beast/) | **自己進化エージェント: 生成、進化、ロールバック。** Beast (1) DSL サーフェスで NeoGraph トポロジを作成し、3 つのゲート (精緻化 → 厳密なコンパイル + 変換検証 → 静的検証) を通じて一貫性を証明し、(2) コンパイラをフィットネス ゲートとして使用し、`evolve()` を介して実際の突然変異演算子でそれを進化させ、(3) チェックポイント記述子で生存者を生成し、その実行を以前の状態に巻き戻します。スーパーステップ (`load_by_id` タイムトラベル)。 NeoGraph だけが安全にするカテゴリです。ハーネスはデータであり、DSL コンパイラーは単一ノードが実行される前にデータの一貫性を証明します。オフライン スタブ作成者、DeepSeek v4 プロ (OpenRouter) が実際にコンパイラ診断自己修復ループを使用してハーネスを作成する **ライブ バリアント**、モデルがツール カタログを読み込んでバインドされたツールを自律的に呼び出す ReAct エージェントを作成する **apex バリアント**、MCP 経由でツールを検出し、Python MCP サーバーとして *不足しているツールを作成*する **フォージ バリアント**、**スクリプトモデルが NODE LOGIC (オプションで独自の `goto` フローを制御するモデルで記述されたコードを実行する `script_node`、オプションで Sandbox2 分離) を作成するバリアント**、および **evolve バリアント** - 実際の出力スコア付き適合性を備えたミーム ループ (ターゲットを計算するまで算術パイプラインの配線を進化させる): ダーウィンの突然変異/選択 (オフラインでクライミングを検証) と取得したソリューションの Lamarckian LLM インジェクション。実際の実行に対してコヒーレンスバリデーターの判定を経験的にクロスチェックする **ゲート評価** ハーネス (CI ゲート可能な健全性)、それを数千のファズ化ミュータントにスケールし、保証の境界を正直にマッピングする **ゲートファズ** (正直な効果契約に比べて健全、ランタイム バックストップは嘘をついた契約を 500/500 で阻止する) を提供します。スモールステップセマンティクス + エフェクトラティス、サンドボックスの **コントラクト派生 seccomp** レイヤー、および **ボールドウィン** ペアに関する進歩/無故障定理 — ハーネス トポロジのダーウィン派 vs ボールドウィン派 vs ラマルク派のミーム進化: 基本バリアント (勾配のないグローバル プラトー) と **敵対的 ** バリアント (`baldwin_adv`、欺瞞的勾配ランドスケープ + リアル)盲目的な検索が積極的に *騙される*) ヒルクライム学習。どちらも、学習誘導型進化がグローバルブラインド進化には到達できないことを（CIゲートで）示し、ボールドウィン対ラマルクの比較を正直に報告しています。30の構成スイープにより、ホイットリー・ボールドウィン＞ラマルクの逆転は離散トポロジー（測定、名前付きメカニズム、想定されていない）では**再現されない**ことがわかります。 **baldwin_llm** デモは、モデル自体を学習演算子 (算術パイプラインの `?` ステージを満たす) にするため、トグルは文字通りになります。Baldwin は世代ごとにモデルを再調査し、Lamarck は修正を継承 (呼び出しの数が少なくなります) に保存します。そして、**小説家**は、一行の前提を、ライトノベルほどの長さの `.txt` に変えます。これは、「途中で迷った」を解決する、明示的なストーリー状態 (概要/聖書/概要チャネル + 自己ループするライター ノード) のグラフです。各章は、前のテキスト全体ではなく、コンパクトな外部化された状態に対して新たに生成され、単語が書かれる前に配線を証明するコヒーレンス ゲート (オフラインの決定論的スタブ、`OPENROUTER_API_KEY` 用)本物の散文）。 |
