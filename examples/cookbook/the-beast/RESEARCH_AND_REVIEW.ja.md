# 「The Beast」 — コードレビューと学術的な位置づけ

**Languages:** [English](RESEARCH_AND_REVIEW.md) | [한국어](RESEARCH_AND_REVIEW.ko.md) | [日本語](RESEARCH_AND_REVIEW.ja.md) | [简体中文](RESEARCH_AND_REVIEW.zh-CN.md)

`the-beast/` クックブック (6 つのプログラム、約 1.6k LOC) の統合レビューと
その学術的な位置づけ。このレビューは 4 つの独立したエージェントによって作成されました
並列実行 — ソースに対して 1 人のコード レビュー担当者 (Opus) と 3 人のコード レビュー担当者
arXiv/Scholar MCP 検索を使用して文献を調査し、ここで調整します。毎
以下の arXiv ID は、検索中にスカウトによって要約検証されました。

クックブックは、バリアントごとに自己オーサリング エージェント システムに構築されます。

|プログラム |それが示すもの |
|---|---|
| `the_beast.cpp` | strict Core JSON でトポロジを生成し、それを `evolve()` し、チェックポイント作成機能を介してロールバックします。オフライン、決定的。 |
| `the_beast_live.cpp` | LLM はハーネスを作成します。 3 つのゲートがそれを検証します。診断は自己修復ループを駆動します。 |
| `the_beast_apex.cpp` |モデルは ReAct ツール呼び出しエージェントを作成します。バインドされたツールで実行され、それらを自律的に呼び出します。 |
| `the_beast_forge.cpp` | MCP 経由でツールを検出します。いずれかが欠落している場合、LLM は **Python MCP サーバー**を作成し、起動して再検出します。 |
| `the_beast_script.cpp` | `script_node` は、ゲート + ランタイム効果コントラクトに基づいて、独自の `goto` フローを制御する LLM で書かれた Python を実行します。オプションで Google Sandbox2 によって分離されます。 |
| `the_beast_evolve.cpp` |ミーム ループ: ダーウィンのトポロジー突然変異 + **実際のハーネス実行適合度** + 遺伝シードとして注入されたラマルクの LLM 洗練。 |

**ステータス: (c) 実装および検証済み。** `script_node` の効果コントラクトが完成しました。

`"net"` 機能の不在 seccomp-blocks `socket`/`connect`/…、

`caps=["net"]`→`{"socket":"SOCKET_CREATED"}`。これでコードレビューの調査結果 5 は終了です
