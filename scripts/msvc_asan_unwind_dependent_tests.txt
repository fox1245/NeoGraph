# coroutine locals during exception unwinding. One test name per line; a line that starts with # is a comment.

# of a coroutine that ends by an exception or that catches one inside a try block, and the job leaves out the tests
# listed here. When the probe passes, the job runs them, and fails if this file still lists any: remove the entries.
